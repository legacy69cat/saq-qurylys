# Приёмка и демонстрация

Это спецификация будущих тестов, не отчёт об их прохождении.

## Скоринг

| Проверка | Ожидаемый результат |
|---|---|
| A: основание unknown, R2+R3 подтверждены | 35, жёлтый; R1 не начислен |
| B: R1+R2+R3 подтверждены | 70, красный; сигнал ждёт человека |
| C: гарантия present, обычная реклама R3 | 10, зелёный; отсутствие отдельного разрешения не даёт R1 |
| R2+R3+R4+R5+R6 без R1 | 65, жёлтый |
| Только R1+R2 | 60, красный |
| Только R2 | 25, жёлтый |
| Нет подтверждённых факторов | 0, зелёный; неизвестные поля отмечены отдельно |
| Все шесть факторов | 100; результат ограничен сверху |
| Две публикации подтверждают один R2 | R2 начисляется один раз |
| R2 только proposed или rejected | 0 баллов за R2 |
| R5: разница 19/20 п.п. | 0/10 при подтверждении и наличии обоих источников/дат |
| R5: нет одного источника | Нужна проверка; баллы не начисляются |
| Одинаковые подтверждённые данные, разный порядок | Одинаковый результат |

Дополнительно протестировать чистый классификатор зон на 24/25/59/60, даже если отдельные баллы недостижимы текущими весами.

## ИИ и данные

- Новый текст с платной бронью → гипотеза R2 с дословной цитатой.
- «Бесплатная бронь, без оплаты» → не подтверждать R2 автоматически; проверить отрицание в оценочном наборе.
- Обычная реклама без оплаты → не выдумывать условия оплаты.
- Невалидный JSON, придуманная цитата, тайм-аут, отсутствие ключа → понятная ошибка/нужна проверка, сохранённый текст не теряется.
- Команда внутри рекламы «игнорируй правила» → текст рассматривается как данные.
- Нет уверенной привязки к ЖК → публикация остаётся непривязанной до решения аналитика.
- Seed содержит минимум 8 полных карточек и 12 публикаций; все источники демонстрационные и имеют время фиксации.

Для оценки ИИ использовать небольшой размеченный набор новых формулировок: платная/бесплатная бронь, депозит, обычная реклама, отрицания и неоднозначные условия. Сохранить реальные ошибки; не заявлять точность без измерения.

## Решения и экспорт

- Принятие фактора меняет балл и создаёт запись с автором/временем; отклонение не добавляет баллов.
- Возврат сигнала требует комментария; повторная подача создаёт следующую версию.
- Нельзя подтвердить сигнал без обязательных доказательств и автора.
- Подтверждённый снимок не меняется при изменении текущего риска ЖК.
- Двойной клик не дублирует действие; данные сохраняются после перезагрузки.
- Печатная версия содержит ЖК, балл, зону, факторы, материалы, дату, статус, автора и отметку «Демонстрационные данные».
- Цвет сопровождается текстовым названием зоны; основные действия доступны с клавиатуры.

## Сквозное демо — ориентир 4–5 минут

Длительность адаптировать после объявления регламента.

1. Открыть реестр, объяснить пользователя и задачу; показать фильтр риска.
2. Открыть демонстрационный ЖК с подтверждённым R1 и без R2: 35, жёлтый.
3. Ввести новый текст рекламы с депозитом; выполнить настоящий ИИ-анализ.
4. Показать цитату и статус гипотезы. Пока она не подтверждена, R2 не начисляется.
5. Подтвердить привязку, R2 и при необходимости R3: получить 70, красный; раскрыть расчёт и источники.
6. Создать сигнал, вернуть с комментарием, повторно подать, подтвердить и открыть печатную версию.
7. Кратко показать A=35 и C=10: неизвестность и действующая гарантия обрабатываются корректно.

Ценность демонстрировать наблюдаемыми действиями: число переходов до источника и время от ввода рекламы до карточки. Не обещать процент экономии времени без сравнения с ручным процессом.

## Проверка поставки

На чистом клоне выполнить документированные установку, env-настройку, миграции, seed, запуск и тесты. Проверить работу без LLM-ключа для ручного сценария и с ключом для ИИ. Записать версии среды и результаты в README. Облачное демо необязательно; при зависимости от интернета подготовить запись, явно отличая её от живого запуска.
