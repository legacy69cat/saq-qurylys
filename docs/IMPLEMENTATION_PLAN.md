## Очередь задач

### P0 — обязательное

- [x] T01. Каркас приложения, lock-файл, `.env.example`, команды lint/typecheck/test/build.
- [x] T02. Миграции и идемпотентный seed с 8 полными ЖК, 12 публикациями, источниками, датами и метками «Демо».
- [x] T03. Расчёт R1–R6, уникальность факторов, зоны, тесты A/B/C и пограничных условий.
- [x] T04. Реестр с поиском/фильтром и карточка со всеми обязательными полями.
- [x] T05. Ручной ввод публикации, сохранение текста, даты и источника, привязка к ЖК.
- [x] T06. Gateway-адаптер, проверка ответа, точные цитаты, состояния загрузки/ошибки/неуверенности. Живая оценка модели остаётся частью T09 и требует ключа.
- [x] T07. Принять/отклонить фактор; транзакционный пересчёт и журнал автора/времени.
- [x] T08. Версии сигнала, подтвердить/вернуть, комментарий возврата, печать.
- [ ] T09. Сквозные и негативные проверки, запуск с чистого клона, документация использования ИИ.
- [ ] T10. Демо, питч, резервная запись, фиксация SHA и обеспечение доступа жюри.

Зависимости: T02 → T03/T04/T05; T05 → T06; T03+T06 → T07; T07 → T08; все P0 → T09 → T10. Ранний сквозной проход важнее отдельных законченных экранов.
