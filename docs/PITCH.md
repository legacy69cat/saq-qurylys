# Сценарий защиты и архитектура за 5 минут

## 0:00–0:40 — проблема

Аналитик видит рекламу квартир, но сведения о застройщике, документах, ходе строительства и жалобах разрознены. SAQ связывает объявление с объектом, выделяет проверяемые признаки и собирает материалы для решения. Продукт не устанавливает правонарушение.

## 0:40–1:30 — обзор

Запустить `npm run demo -- --ai` после сборки. Показать баннер вымышленных данных, 8 ЖК и карточки A/B/C: 35/жёлтая, 70/красная, 10/зелёная. У C есть гарантия: отсутствие отдельного разрешения не превращается в R1. Открыть доказательство из объяснения балла.

## 1:30–3:30 — новый материал

Открыть Контур 07. Добавить новое вымышленное объявление с суммой, выбранной во время показа: «ЖК Контур 07 строится. Продаём квартиры. Внесите депозит … тенге». Запустить ИИ. Показать дословные цитаты R2/R3, уверенность модели и неизменившийся балл. Подтвердить гипотезы вручную — балл изменится с 35 до 70. Создать сигнал, вернуть с комментарием, создать следующую версию, подтвердить и открыть печать.

При недоступном провайдере прямо сказать об ошибке и показать ручной путь. Не выдавать заранее записанную демонстрацию за текущий ответ ИИ. Резервная техническая видеозапись создаётся `npm run test:case:live`.

## 3:30–4:15 — дополнительные возможности

Показать скриншот → OCR → редактирование текста → предварительную оценку и тот же сценарий в Telegram. Коротко показать живой мониторинг публичных публикаций на production. Не обещать полноту рекламы площадок. Дрон — визуальные наблюдения, а не автоматическое разрешение строительства.

## 4:15–5:00 — инженерия

- Next.js/React — страницы и серверные действия. `src/domain` — чистые правила риска и валидация, без вызовов ИИ.
- `src/server/db` — транзакции, источники, журнал и неизменяемые версии сигналов. Локально SQLite, в Vercel Turso через общий асинхронный интерфейс.
- `src/server/ai` — внешний анализ и OCR. Выход проверяется схемой; цитата должна входить в исходный текст. ИИ не пишет подтверждённые факторы напрямую.
- Соцсети — Apify и ограниченная очередь с бюджетом; Telegram — защищённый webhook, лимиты и дедупликация.
- Тесты риска, ошибок, прав доступа, desktop/mobile и отдельная платная live-приёмка. Homeportal/eQurylys возвращают материалы, окончательное сопоставление проверяет человек; промышленное восстановление/нагрузка — следующие этапы.

Ценность измерять на пилоте: время от новой публикации до сигнальной карточки, доля гипотез с подходящими цитатами, доля исправлений аналитиком. Не придумывать проценты экономии без измерений.

Перед сдачей указать точный SHA, проверить публичность GitHub и согласовать с организаторами правила изменения версии после отсечки. Понимание кода и выступление команды не могут быть заменены автоматическими тестами.
