# Финальная сдача SAQ QURYLYS

## Что передать жюри

1. Репозиторий: https://github.com/legacy69cat/saq-qurylys
2. Полный SHA выбранного коммита (`git rev-parse HEAD`) и постоянную ссылку вида `https://github.com/legacy69cat/saq-qurylys/tree/<SHA>`.
3. Успешный запуск [Verify](https://github.com/legacy69cat/saq-qurylys/actions/workflows/check.yml) с тем же `headSha`.
4. Онлайн-версию https://saq-qurylys-one.vercel.app и учётную запись, переданную отдельно от публичного репозитория.
5. Для проверки без внешних доступов — инструкции из README: `npm ci`, `npm run build`, `npm run demo`.

Текст этой инструкции не объявляет текущий HEAD окончательно сданным: сдаваемую версию фиксирует команда. После передачи SHA не меняйте его смысл и не переписывайте историю. Позднейшие исправления получают новые коммиты и согласуются с правилами организаторов.

## Воспроизводимая проверка

```bash
npm ci
npm run check
npm run verify:case
npx playwright install chromium
npx playwright test
npm run test:auth
```

CI выполняет эти проверки на чистой установке. Число тестов и итог берутся из конкретного запуска, а не из устаревающей записи в документации.

## Что показать

- Карта, фильтрация, карточка объекта, источник и дата сведений.
- Изолированное демо: Контур 07 → новая публикация → цитируемые гипотезы → подтверждение → 35→70 → сигнал → возврат → новая версия → подтверждение → печать/PDF.
- Мониторинг: автоматически собранные публикации, кандидаты ЖК и подтверждение привязки человеком.
- Telegram: предварительный отчёт и появление обращения в `/inbox`, статус и комментарий проверки.
- Дополнительно: OCR, снимки с дрона, результаты Homeportal/eQurylys.

Не добавляйте учебные подтверждения нарушений в реальные карточки. `/?simulation=1` позволяет показать условные баллы на реальной карте, но не заменяет сквозное демо с сохранением материалов. Выход из симуляции — `/?simulation=0`.

## Границы проверенного результата

- R1/R4/R5/R6 требуют проверяемых материалов. Результат поиска реестра не подтверждает отсутствие правового основания сам по себе.
- Парсинг, OCR и внешние API зависят от доступности, кредитов и лимитов. Полный охват соцсетей не заявляется.
- Live-сценарий с моделью был пройден 19.10.2026. После изменения инструкции на `saq-ad-3` повторная проверка расширенного набора остановилась на HTTP 429. Прошлый успех не является приёмкой последней инструкции. Подробности: [матрица](CASE_MATRIX.md).
- В Telegram есть постоянная очередь текстов/OCR и последнее решение; нет полной истории редактирования, автоматического возврата решения в чат и durable outbox.
- Нагрузочные испытания, SSO/MFA, подтверждённое восстановление облачной БД и регламент удаления обращений не входят в доказанную готовность этого прототипа.
