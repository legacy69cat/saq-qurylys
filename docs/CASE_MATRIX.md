## Приёмка без ключей

```
npm ci
npm run check
npm run verify:case
npx playwright install chromium
npx playwright test
npm run test:auth
```

Для ручного показа: `npm run demo` после сборки, http://127.0.0.1:3300. Данные временные и очищаются при остановке; production не меняется. Это специальный режим для жюри, не включение демоданных в рабочем сайте.

## Настоящий ИИ

В игнорируемом `.env.local` должны быть действующие AI_GATEWAY_API_KEY и AI_GATEWAY_MODEL. `npm run test:case:live` запускает отдельный сервер и временную SQLite, генерирует новое объявление, вызывает модель через UI и проходит подтверждение/возврат/выгрузку. Тест не подменяет ответ провайдера, не повторяет неуспешный платный запрос автоматически и не включён в offline CI. Артефакты — `test-results/live-case`: видео, печатный PDF, скриншот. Видеозапись техническая, без озвучки.

Для ручной работы с реальной моделью: `npm run demo -- --ai`. Внешние сервисы сбора/Telegram и облачная БД при этом всё равно отключены.

## Не считать обязательными интеграциями

Homeportal подключён к публичному поиску; остальные ссылки справочника не выдаются за автоматический опрос. Парсинг соцсетей, Telegram, OCR и дрон реализованы как дополнительные функции с указанными ограничениями. Ни отсутствие доступа к реестру, ни текст модели не устанавливают нарушение.

Зелёные тесты не обещают максимальные баллы жюри и не заменяют питч/приёмку людьми. Статус чистой установки в GitHub CI надо сверить по конкретному сдаваемому SHA. Дата фиксации сдаваемой версии определяется командой, а не этим документом.

## Зафиксированный результат проверки

19.10.2026: локальные `npm run check` (154 теста, проверка типов, lint и production-сборка) и `npm run verify:case` прошли. Сквозной `npm run test:case:live` с настоящей моделью `google/gemini-2.5-flash` прошёл: новое объявление → две цитируемые гипотезы → ручное подтверждение → 35→70 → возврат сигнала → версия 2 → подтверждение → PDF. Сохранены техническое видео и печатная карточка. Это результат конкретного запуска, а не гарантия доступности внешнего провайдера.

## Автоматизация открытых источников — 20.10.2026

Homeportal подключён к публичным POST `getobjects` и `illegal-objects` (маршруты проверены по клиенту портала и живому ответу). Кнопка в карточке объекта сохраняет результаты поиска по БИН/названию, время, адреса и ссылки на записи. Ежедневный cron дополнительно проверяет до шести наиболее давно проверенных реальных объектов. Поиск ограничен тремя страницами на раздел; неполнота и недоступность явно отмечаются. Результаты — кандидаты для сопоставления, не автоматическое подтверждение R1. eQurylys также подключён: точный поиск организации по БИН, отдельный сохранённый материал; запись организации не доказывает наличие разрешения объекта. Сервис аккредитаций, указанный клиентом eQurylys, на момент проверки возвращает ошибку TLS-сертификата, поэтому не подключён. Остальные государственные источники пока не подключены.

Импорт Apify читает страницы уже оплаченного набора до 1000 записей вместо обрезания до целевого лимита поиска. При достижении предела задача помечается как неполная. Бюджет сбора остаётся прежним, полнота соцсетей не гарантируется.
