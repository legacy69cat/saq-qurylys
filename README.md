# SAQ QURYLYS

Прототип для аналитика МИО: объединить сведения о строящихся ЖК, выявить признаки предложения оплаты в рекламе и подготовить объяснимый сигнал для проверки человеком.

**Состояние на 14 октября 2026: анализ и планирование. Приложение ещё не реализовано; команд запуска продукта пока нет.**

## Планируемый MVP

1. Реестр ЖК с поиском и фильтрами риска.
2. Карточка ЖК: застройщик, стадия, основания, источники и публикации.
3. Ручной ввод новой рекламы и анализ условий оплаты с помощью ИИ.
4. Подтверждение факторов аналитиком и воспроизводимый пересчёт риска.
5. Сигнальная карточка с подтверждением/возвратом, историей и печатной версией.

Минимум данных: 8 вымышленных ЖК, 12 публикаций, контрольные кейсы A/B/C. Все примеры явно помечаются как демонстрационные.

## Предлагаемый стек

TypeScript, React/Next.js, SQLite, серверный адаптер LLM, Vitest и Playwright. Это проектное предложение: версии и конкретный провайдер будут зафиксированы при реализации. Локальный запуск — основной способ демонстрации; деплой необязателен.

## Принципы

- Неизвестные сведения не равны отсутствию правового основания.
- ИИ формирует гипотезу и цитату, человек подтверждает фактор.
- Балл вычисляется правилами, а не ответом модели.
- Сигнал — повод для проверки, а не утверждение о нарушении.
- Демоданные не содержат настоящих персональных данных или обвинений в адрес реальных компаний.
- Секреты и исходные локальные документы не коммитятся.
