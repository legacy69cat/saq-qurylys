# Развёртывание в Vercel

Проект: https://vercel.com/imastikbaev-4596s-projects/saq-qurylys
Сайт: https://saq-qurylys-one.vercel.app

Данные хранятся в Turso Starter, подключённом через Vercel Marketplace, регион bom1. В Vercel файловая SQLite запрещена; без TURSO_DATABASE_URL приложение не создаёт временную базу. Локальная разработка и изолированные тесты используют SQLite. Схема общая; запросы асинхронные, изменения выполняются в транзакциях.

Production-переменные: TURSO_DATABASE_URL, TURSO_AUTH_TOKEN, APP_ENV=production, SAQ_AUTH_MODE=session, SAQ_DEMO_MODE=0, APIFY_TOKEN, APP_URL, CRON_SECRET, APIFY_WEBHOOK_SECRET. Секреты не должны попадать в репозиторий или логи. AI_GATEWAY_API_KEY не настроен; доступны правила скоринга и ручная проверка.

Vercel Hobby допускает ежедневный Cron: в проекте 12:00 UTC (17:00–17:59 Алматы). Cron запускает короткий цикл; завершение Apify вызывает защищённый webhook, который читает фактический результат по сохранённому run_id и продолжает очередь. Один вызов обрабатывает максимум три текущих запуска и стартует максимум один новый. Сохранён лимит $1/24 часа. Уведомление не является доказательством — данные повторно читаются из Apify. Повторная доставка не дублирует импорт, блокировка в Turso исключает одновременные циклы. Неопределённый результат платного запроса требует сверки и не повторяется автоматически.

Не запускать одновременно локальный сборщик с отдельной копией базы: бюджеты разных баз независимы. Основная база теперь облачная. Экспорт/резервные копии облачной базы и восстановление нужно настроить в Turso; scripts/backup.ts предназначен только для локальной SQLite. Бесплатный тариф не означает наличие отдельной проверенной аварийной копии.

Публикация выполнена CLI из локального проекта. Для следующих обновлений: проверки, миграции совместимые с текущей версией, `vercel --prod`. Автодеплой из GitHub пока не подключён. Preview не подключать к production-базе; использовать отдельную базу и секреты. Перед миграцией делать резервную копию. Пароль администратора передан отдельным локальным файлом, не переменной окружения.

Ограничения: нет гарантии полного охвата соцсетей, OCR/распознавания речи и автоматической проверки всех государственных реестров. Результат скоринга — приоритет проверки, не вывод о нарушении. Регламент мониторинга расходов, копирования данных, управления доступом и реагирования требует владельца со стороны команды.
